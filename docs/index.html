Personal Dashboard

Dashboard personal en Python con integración de Gmail, Calendar, Tasks, Drive y briefing IA

🚀 Instalación rápida

git clone https://github.com/gmolina75/personal-dashboard.git
cd PersonalDashboard
python -m venv venv
.\venv\Scripts\activate  # Windows
pip install -r requirements.txt

⚙️ Configuración

Crea un archivo .env con tus credenciales de Google.
